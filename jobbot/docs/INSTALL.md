# Jobbot — התקנה למשתמש (בלי טרמינל)

## Windows

1. הורד / קבל את **`Jobbot-Portable-0.1.0.exe`** מתיקיית `release/`.
2. לחיצה כפולה על הקובץ.
3. Jobbot נפתח. אין צורך ב-npm.

חלופה: חלץ `Jobbot-Windows-x64.zip` ולחץ על `Jobbot.exe`.

## Linux

1. הורד `Jobbot-0.1.0.AppImage`.
2. סמן כניתן להרצה → לחיצה כפולה.
