# Jobbot ל-Mac

1. הורד **הפעל-Jobbot.app.zip** → חלץ → **קליק ימני על האפליקציה → פתח**
2. אחרי כל עדכון — אותה לחיצה שוב
3. פעם ראשונה: כמה דקות · אחר כך מהיר (צריך Node מ־nodejs.org)
4. אם אין .app: הורד **הפעל-Jobbot.command.zip** (מגיע עם הרשאת הרצה)
5. אם .command עדיין חסום, הדבק בטרמינל:
   `chmod +x ~/Downloads/הפעל-Jobbot.command && open ~/Downloads/הפעל-Jobbot.command`
   או: `chmod +x ~/Desktop/הפעל-Jobbot.command && open ~/Desktop/הפעל-Jobbot.command`
