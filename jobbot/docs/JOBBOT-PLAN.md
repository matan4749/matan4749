# Jobbot — תוכנית הפצה

## ראשי (Mac)
**הפעל-Jobbot.app.zip** — לחיצה כפולה / קליק ימני → פתח.  
מושך ענף `cursor/jobbot-desktop-app-4bd4` ל־`~/Desktop/Jobbot-src` ומריץ `npm install && npm run build && npm start`.

גיבוי: `הפעל-Jobbot.command.zip` (mode 755 בתוך ה-zip).
